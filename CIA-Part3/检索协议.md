# 检索协议（给 Claude 读）

> **本文件是根目录 `检索协议-模板.md` 的 CIA Part 3 实例**——以下内容（板块分布、IPPF、Gleim/兆泰 等）均为本科目特有。其他考试建档时复制模板，替换为自己的大纲与教材。

> 本文件定义知识库的操作方式。任何窗口的 Claude 收到考题后，按下述流程操作。

## 流程（检索纪律 ⚡）

1. **判断题型板块**（40% IT 类题 → VI 板块；治理/风险/职业道德 → I/II 板块 + IPPF；计算题 → VII 板块）——IPPF 类题先查 [[IPPF索引]] 定位条款号，再跳 **B 块精讲笔记**（[[B-01 强制性指南与内部审计定义]]~[[B-07 工作标准2300-2600系列]]，含官方版+红皮书双源锚点），精讲未覆盖的条款再翻红皮书/官方版原文
2. **先查 [[_索引]] 锁章节**：Read `_索引.md` 定位 **章 + 节**，绝不直接全目录扫描
3. **只 Grep 单文件**：锁定章节后，Grep 仅限 `教材原文/NN-章节名.md` 单文件，禁用 `教材原文/` 全目录扫（命中噪音×N，拖慢定位）
4. **并行读取**：已知节编号（如 `11.3`）时，可直接用 `offset` 跳读，无需先搜；定位+读取尽量在**同一条消息内并行发起**
5. **做题输出默认完整四段式**（见下，2026-08-02 定稿，紧凑版已废弃）
6. **本地教材兜底优先**：Gleim 单文件未命中 → 按大纲板块立即切 **兆泰/应试指南**（兆泰按官方大纲四大板块组织，应试指南按大纲四章，均覆盖 IT 控制/COBIT）→ 本地有确凿依据就下结论。**先本地、后外部**
7. **外部搜索设上限**：仅当本地教材无法定论（如核对真题来源/选项争议）才外部搜索；**限 2 轮**，无果即放弃并如实标注"待确认"，不可反复死磕（2026-08-02 教训：3/100 COBIT 题在外部找标准答案耗时最长，本地兆泰其实一次能定）
8. **错题入库（强制约定，顺序在答案之后）**：用户发来的**每一道题都视为错题**（定稿："凡是我发的题，都说明我不会"）→ **答案讲解先行，入库安排在公布答案之后**（2026-08-02 反馈：用户需先看答案继续刷题，错题入库/汇总更新等事项一律排在答案输出之后，不可让入库工作拖延答案）。入库 = 追加到 `错题库/错题记录.md`（单文件，每条一个 `## 错题 YYYY-MM-DD-NNN` section），格式见下；**同时更新 `错题库/_汇总.md`**（按章节/板块累计，薄弱点统计）

## 做题输出模式

### 完整四段式（默认，2026-08-02 定稿）
> 反馈：紧凑模式"太简单，很难一次理解到位"→ **恢复完整讲解，全程四段式，废弃紧凑版**。

- **输出顺序（2026-08-02 定稿）**：**答案先出**——四段式讲解作为第一块输出；错题入库、汇总更新等一切收尾工作放在答案之后，不得前置或并行拖延。
- **考点定位**：`大纲板块 VI → 11.3 身份认证与加密`；IPPF 类题：`IPPF 2110 治理`（跳 [[IPPF索引]] → B 块精讲 [[B-05 工作标准2100系列]] → 红皮书/官方版原文）
- **准则/大纲依据**：该知识点的理论来源，引用教材原句（标注 `文件:行`）
- **思路拆解**：解题逻辑，为什么选这个。**抓核心因果链，精炼表达**（2026-08-02 反馈：勿层层铺陈、勿啰嗦）
- **干扰项解析**：其他选项为何错，考点陷阱、易混概念

## 错题库条目格式（单文件）

**全部错题存在 `错题库/错题记录.md`**（不拆多文件）。每道题一个 section，新题追加在文件顶部（倒序）。

```markdown
## 错题 YYYY-MM-DD-NNN — 主题
> 题号 xx/100，单选题。（发题即错题约定）

- **题目**：…（含选项）
- **正确答案：X**
- **错因分类**：概念混淆 / 准则不熟 / 计算失误 / 审题失误
- **知识点ID**：VI-11.3 身份认证与加密
- **复盘**：考点解析 + ⭐陷阱 + 关联错题（编号）
```

> 知识点ID 格式：`板块罗马数字-章.节 知识点名`；IPPF 类错题用 `IPPF-条款号 条款名`（如 `IPPF-2110.A1 治理`）。每入库一题**立即更新 `错题库/_汇总.md`**（按板块统计薄弱点）。

## 精讲笔记格式

> 精讲笔记两类：**A 块**（Gleim 20 章，`精讲笔记/NN-章节名.md`）；**B 块**（IPPF 条款精讲，`精讲笔记/B-0X 文件名.md`，每条款一个考点，含 官方原文/核心结论/逻辑拆解/考法/易错点/融合补充/锚点/关联考点，锚点双源=官方版 2017 + 红皮书）。B 块清单见 [[_索引]]「B 块 IPPF 精讲笔记」。

```markdown
# 考点：<名称>
- 大纲位置：板块 VI → 11.3 身份认证与加密
- 准则依据：IPPF xx 条（如适用）
- 核心结论：…
- 易错点：…
- 关联考点：[[01-治理]]
```

## 边界

- 知识库只回答 **CIA Part 3 大纲内** 的内容；大纲外的题明说"不在考纲范围"
- OCR 原文可能有错字，引用时如明显异常（如 `ⅡIA`），按常识纠正后标注
- 教材原文是基础层；**优先用精讲笔记**，笔记没有的再翻原文
