> 条目格式见 [[检索协议]] 的"错题库条目格式"。

## ⚡ 约定（2026-08-01 定稿）
用户发的**每一道题**都视为错题（原话："凡是我发的题，都说明我不会"），讲解后**必须入库**，并**立即更新 [[_汇总]]**（薄弱点统计）。

## 结构
- [[错题记录]] ← **全部错题**（单文件，每条 `## 错题 YYYY-MM-DD-NNN` section，新题追加）
- [[_汇总]] ← **薄弱点统计**（按章节/板块累计，每错题入库后更新）
