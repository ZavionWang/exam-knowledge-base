## ⚠️ 知识点ID 格式说明（2026-09-26 补充）

本实例的 210 条记录使用的是**早期格式** `板块罗马数字-章.节 知识点名`，为保持历史记录原样**未做改写**。

**新库请用现在的格式**（见 `检索协议-模板.md`）：`<机器键> <知识点名>`，**第一个空格前是机器键**——
机器键必须能在 `精讲笔记/` 里找到对应考点，例如 `VI-11.3 身份认证与加密`、`D4-B-4.10a BCP 与 DRP 的关系`。

拿这个实例跑校验可以直观看到早期格式的问题：

```bash
python tools/kb-id.py --check --project CIA-Part3
# 结果：规范 0 · 标准类 4 · 归档旧格式 203 · 不合规 3
#       同一知识点的多种写法 15 组，其中「实为同一考点、只是写法不同」2 组：
#           V-9.1 与 V-09.1 · V-9.5 与 V-09.5（零填充不一致 → 薄弱点统计会劈成两项）
#       真缺陷 3 条：V-8.*（通配符）、IPPF-框架（…、兆泰数据分析（…（名称与键没分开）
```

这正是「机器键」要独立出来的原因：**ID 段必须可解析，名称一律放空格之后。**
