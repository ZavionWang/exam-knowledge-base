## 错题 2026-08-09-021 — 银行调节：在途存款=12,340（两侧归一）

> 题号 25/100，单选题。用户发题即视为错题（错题入库约定）。

- **题目**：12/31 银行对账单余额 12,000，账面现金余额 17,400，未兑现支票 6,900；银行将 40 利息贷记账户但账面未记。若无错误，在途存款总额？
  A. 5,400　B. 12,260　C. 12,300　D. 12,340
- **正确答案：D（12,340 美元）**
- **错因分类**：计算失误（银行余额调节四要素）
- **知识点ID**：VII-14.5 现金和应收账款（银行余额调节表）
- **复盘**：
  - **依据**：[Gleim 14:696-727] 企业已记银行未记=未兑现支票（**减**）/在途存款（**加**）；银行已记企业未记=银行利息（**加**）/服务费（**减**）；两侧调到同一正确余额
  - **计算**：设在途存款=X，银行侧 12,000+X−6,900 = 账面侧 17,400+40=17,440 → 5,100+X=17,440 → **X=12,340** ✅ 验证 12,000+12,340−6,900=17,440 ✓
  - ⭐陷阱：**利息 40 加到账面侧**（漏了→12,300 错选 C）；**未兑现支票在银行侧减**（符号反→错）
  - ⭐记忆：**银行侧调"在途存款+/未兑现支票−"；账面侧调"银行利息+/服务费−"；两侧收敛同一正确余额**

## 错题 2026-08-09-019 — 遗留系统维持：无限制授权紧急抢救（独立+将替换→快速救火优先）

  A. 紧急抢救行动后必须马上对行动情况进行审查　B. 禁止开展紧急抢救行动　C. 应用报告编制程序来更新交易文档　D. 通过没有限制的方式授权开展紧急抢救行动
- **正确答案：D（通过没有限制的方式授权开展紧急抢救行动）**
- **错因分类**：概念混淆（遗留系统场景 vs 常规变更控制）
- **知识点ID**：VI-11.5 程序变更控制（遗留系统维持）
- **复盘**：
  - **依据**：[兆泰:6259-6261] **遗留系统**=从主机/终端转 C/S、B/S 过程中因硬件/技术/人才难以继续发展而形成的过时系统（**即将被替换**）；[兆泰:9977-9981] 新系统替代旧系统=转换
  - **D ✓ 最佳**：场景三特征=①**数据库互不关联**（系统独立→补丁影响隔离、低耦合）②故障频繁（需**快速响应**）③即将被替换（不值得投入严格变更控制）→ 维持运行最佳 = **无限制授权紧急抢救**，让 IT 立即救火不被流程束缚 ✅
  - **A ✗**：事后审查是**常规变更控制**的正确做法（对正式生产系统），但本题是"独立+临时+将替换"的遗留系统，每次补丁都审查会**延误恢复**，非最佳
  - **B ✗**：禁止=系统停摆；**C ✗**：报告编制程序更新交易文档与补丁抢救无关
  - ⭐陷阱：**题干"数据库互不关联"是信号词**——系统彼此独立，紧急补丁影响隔离，故可无限制授权；若关联紧密则需严格管控

- **正确答案：B（购买看跌期权）**

## 错题 2026-08-02-005 — 高低点法的适用条件（业务量与成本的正相关）

> 题号 19/100，单选题。用户发题即视为错题（错题入库约定）。本题带「清单A/清单B」表格，原题复制时清单缺失，用户已补发。

- **题目**：在分析综合成本（混合成本）时，最适用高-低方法的情形是：高业务量与高额成本之间存在何种关系（清单A）、低业务量与低额成本之间存在何种关系（清单B）？
  | | 清单A（高业务量↔高额成本） | 清单B（低业务量↔低额成本） |
  | A | 不相对应 | 相对应 |
  | B | 不相对应 | 不相对应 |
  | C | 相对应 | 相对应 |
  | D | 相对应 | 不相对应 |
- **正确答案：C（清单A相对应，清单B相对应）**
- **错因分类**：概念混淆（高低点法的前提假设）
- **知识点ID**：V-8.6 回归与相关性（高低点法 / 混合成本分解）
- **复盘**：
  - 高低点法把混合成本拆成固定+变动：b=(高点成本−低点成本)÷(高点作业量−低点作业量)，a=总成本−b×作业量。**隐含前提 = 成本与业务量线性正相关**：高业务量↔高成本、低业务量↔低成本，高低两点都落在回归直线 y=a+bx 上 [17章:491-533]
  - 只有当高↔高、低↔低**双双相对应**时，两点之差才代表"单位作业量增加对应的成本增量" → C
  - A/B/D ✗ 任一方向不相对应 → 高/低点不代表最大/最小成本，两点连线偏离真实成本性态，推算的 a/b 失真
  - 关键：高低点法**只看两个端点** [08章:1118]，端点代表性决定可靠性
  - ⭐选点：选最高/最低**作业量**对应的点，不是成本数值最大/最小的点；主要批评=端点可能是异常事件 [08章:1139]，端点异常时应改用回归分析

- **题目**：要最大程度地降低未经授权编辑生产程序、作业控制语言和操作系统软件的可能性，以下哪种方法效果最佳？
  A. 数据库访问审查　B. 合规审查　C. 良好的变更控制流程　D. 有效的网络安全软件
- **正确答案：C（良好的变更控制流程）**
- **错因分类**：概念混淆（预防性 vs 检测性控制；变更控制的职责边界）
- **知识点ID**：VI-11.5 程序变更控制
- **复盘**：
  - 题眼："降低…可能性"= 问**预防性控制**；"未经授权编辑生产程序/作业控制语言/OS 软件"= 生产系统资产
  - 变更控制流程 = 授权申请 → 沙箱测试 → 用户验收 → 主管审核批准 → 转生产。本质把"变更"与"授权"**绑定**，没有批准动不了生产版本，从源头堵住
  - A 只限数据库访问权限且事后；B 合规审查宽泛、事后、最弱；D 防外部入侵，防不住内部有权限者改程序
  - ⭐关联：见 004（微观分工=职责分离）。一题问宏观制度，一题问微观分工；"绕过+有技术的人"→ 优先职责分离

## 错题 2026-08-01-002 — 三线模型中内部审计的角色

> 题号 97/100，单选题。用户发题即视为错题（错题入库约定）。

- **题目**：内部审计在组织应用于信息安全设置的"三线模型"方面发挥了什么作用？
  A. 第二线　B. 第三线　C. 第一线　D. 没有任何角色，以保持活动的独立性
- **正确答案：B（第三线）**
- **错因分类**：概念混淆（三线模型各线职责边界不清）
- **知识点ID**：I-1.2 内部审计师在治理过程中的作用（三线模型）
- **复盘**：
  - **第一线**：运营管理层——拥有并直接管理风险，日常运营中实施控制
  - **第二线**：风险管理/合规/内控监测职能——监督、协调、提供指引
  - **第三线**：**内部审计**——独立客观的确认与咨询（评价前两线是否有效）
  - ⭐陷阱：**内审独立 ≠ 三线模型无角色**。独立性指"不参与一线运营、直接对治理机构负责"，内审的角色仍是明确的第三线，二者不冲突

## 错题 2026-08-01-001 — 生产数据与生产程序的访问权限（职责分离）

> 题号 93/100，单选题。用户发题即视为错题（错题入库约定）。

- **题目**：在计算机环境中，下列哪一种访问设置是适当的？
  （1）用户拥有对生产数据的修改访问权。
  （2）应用程序员拥有对生产数据的修改访问权。
  （3）用户拥有对生产程序的修改访问权。
  （4）应用程序员拥有对生产程序的修改访问权。
  A. 1是　2否　3否　4否　B. 1是　2否　3否　4是　C. 1否　2是　3是　4否　D. 1否　2是　3是　4是
- **正确答案：A**（1是 2否 3否 4否）
- **错因分类**：概念混淆（职责分离 / 最小权限掌握不牢）
- **知识点ID**：VI-11.5 程序变更控制（生产环境访问权限 / 职责分离）
- **复盘**：
  - **用户可改生产数据** ✅（数据录入/更新是用户本职）
  - **程序员不可改生产数据** ❌（改数据会破坏审计轨迹、便于舞弊）
  - **用户不可改生产程序** ❌（用户只需用程序，无需改程序）
  - **程序员不可改生产程序** ❌ ⭐关键陷阱：程序员开发在测试环境，投产必须走**变更控制**，由独立库管理员/发布流程把关；否则无职责分离、可写程序绕过控制
  - 排除法：B 错在把④判"是"；C/D 错在把②③判"是"
