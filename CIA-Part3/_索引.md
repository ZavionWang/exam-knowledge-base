# CIA Part 3（内部审计业务知识）— 知识库索引

> **用途**：这是给 Claude（含其他窗口）用的三级定位引擎。
> 用户发出题目 → 先查本索引定位（板块→章→节→知识点）→ 打开对应章节 Markdown → 按固定格式精讲。
> 讲解固定格式：**考点定位 → 准则/大纲依据 → 思路拆解 → 干扰项解析**
> 输出三类：做题讲解 / 考点精讲笔记 / 错题库（带错因+知识点ID）

## 定位锚点（两类）

- **治理/风险/职业道德类题** → 锚 **IIA《国际内部审计专业实务框架》(IPPF) 标准条文**（如 2110、2110.A1、2130.A1-1）→ 先查 [[IPPF索引]]（条款号→正文锚点），再跳 **B 块精讲**（[[B-01 强制性指南与内部审计定义|B-01]]~[[B-07 工作标准2300-2600系列|B-07]]，官方版+红皮书双源锚点），精讲未覆盖再跳 [[教材原文/IPPF红皮书_clean]]
- **业务知识类题**（IT、财务、管理会计、法律经济）→ 锚 **大纲板块 → 章 → 节 → 知识点** → 直接定位下方章节

## 检索协议（给 Claude 读）

1. **定位**：题目 → 判断板块（IT/治理/财务/管理会计/法律…）→ 查上方章节索引 → 锁定章+节
2. **读取**：打开 `教材原文/NN-章节名.md`，用 Grep 在文件内定位知识点（搜关键词或节编号如 `11.3`）
3. **精讲**：按固定格式输出——**考点定位 → 准则/大纲依据 → 思路拆解 → 干扰项解析**
4. **治理/风险类题**：先查 [[IPPF索引]] 对应准则条文（2110 等）→ 跳 B 块精讲（[[B-05 工作标准2100系列]] 等），再结合章节内容
5. **记录错题**：讲解后如有错题，记入 `错题库/` 并标注错因+知识点ID，用于薄弱点统计
