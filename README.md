> 刷了 1000 道题，错题还是那几道反复错；
> 题库解析只告诉你「选 B」，不告诉你 A/C/D 为什么错；
> 问 AI 回答飘忽，还分不清哪句是真的。

**有了这个项目，考生不用再啃教材——直接刷题就能过。**

`exam-knowledge-base` 是给考生配的 **AI 备考搭子**：

| 你真正关心的 | 这个项目怎么解决 |
|---|---|
| 不想啃 800 页教材，没时间 | **教材已提炼成精讲笔记，刷题即学习**：边刷边讲，考点从题目里长出来 |

| 解析太浅，只给答案不讲理 | **四段式讲透：考点定位 → 准则/大纲依据 → 思路拆解 → 每个干扰项为什么错** |

| 备考时间紧 | **毫秒级检索，秒出答案**（实测：5.68 MB 全库检索 ~1 ms） |
| 考完就忘，笔记白做 | **备考即建库**：刷题过程自动沉淀成个人知识库，考完试库也建好了，AI 越用越专业、越用越懂你 |

## 2. 以题代学：不读教材，刷题即过

传统备考路径是 **教材 → 笔记 → 刷题**：先花几个月啃教材，再做题检验——教材读完一半，前面全忘了。

本项目把路径倒过来：**刷题 → 讲透 → 沉淀**，教材的精华已经在精讲笔记里，不需要你自己提炼。

```
传统：800 页教材 ──► 自己整理笔记 ──► 刷题 ──► 错题没人讲
                                    （耗时 3-6 个月，学了就忘）

本项目：直接刷题 ──► AI 四段式讲透 ──► 考点锚定精讲笔记 ──► 错题入库
                    （每题 2-5 秒）      （教材已提炼好）      （越刷越准）
```

> 对考生来说：**教材只是备查的工具书，不再是学习的主线。**

## 3. 备考即建库：考完试，你的知识库也建好了

> 别人备考是消费知识，你备考是**投资知识**。

- 每道错题都带知识点 ID 回写错题库——**错过的、薄弱的，全部沉淀下来**
- 考试结束那天，一个**只属于你的本地个人知识库**也建成了，不会随考试归零
- **AI 越用越懂你**：它知道你错过的每个知识点，讲题越来越针对你的软肋
- 本地私有、离线可用，换科目直接复制目录

## 4. 相比「题库自带解析」和「直接问 AI」，强在哪

> 题库解析是**给答案**，直接问 AI 是**凭记忆**，本项目是**让 AI 有据可依地讲**。

| 维度 | 题库自带解析 | 直接问 AI | **✅ 本项目** |
|---|---|---|---|
| 讲题深度 | 只讲本题（"选 B 因为 B 对"式） | 看模型发挥，无固定结构 | ✅ **固定四段式**：考点定位 → 依据 → 思路拆解 → 干扰项解析 |
| 干扰项处理 | 多数不解释为什么错 | 时有时无，看运气 | ✅ **强制拆解每个干扰项** |
| 知识关联 | 题目孤立，题与题之间无连接 | 无关联 | ✅ **每题锚定章节笔记 + 知识点 ID**，一道题带出一章知识 |
| 错题积累 | 不记录你错在哪、为什么错 | 会话结束即忘，下次还是陌生人 | ✅ **错题结构化回写，带知识点 ID 关联，越刷越准** |
| 答案可追溯 | 解析无出处，无法验证 | 无出处，且**容易幻觉编造** | ✅ **锚定知识库原文**（准则条款 / 教材章节 / 笔记） |
| 讲题一致性 | 稳定但浅 | 每次回答风格飘忽、前后矛盾 | ✅ **检索协议约束**，输出结构稳定 |
| 针对性 | 千人一面 | 无记忆 | ✅ **错题库记录你的薄弱点**，Agent 讲题时针对性强化 |

## 5. 实测性能：毫秒级检索，秒出答案

| 指标 | 实测值 \* |
|---|---|
| 知识库规模 | **60 个 Markdown 文件 · 78,268 行 · 5.68 MB** |
| 索引定位（板块→章→节→知识点） | **~2 ms** |
| 全库关键词检索（任意知识点） | **~1 ms** |
| 打开单篇精讲笔记 | **~1 ms** |
| 一次完整讲题 | **秒出答案**——检索+读取约 5 ms，其余是 AI 生成讲解的时间 |

> \* 实测环境：Windows 11 + PowerShell，对**完整知识库**（含教材原文的全部 60 个文件）检索，3 轮取最优。公开仓库为其子集（37 文件），只会更快。

## 6. 为什么这么快：检索原理

```
  问题 ──► ① 查 _索引（三级映射）──► ② 定位文件名 ──► ③ 打开单文件 ──► ④ 按协议讲题
            O(1) 命中              ~1 ms            ~1 ms             LLM 生成（秒级）
```

1. **文件即数据库**：纯 Markdown 文件系统，无数据库、无索引构建、无启动开销——检索的本质是文件系统 IO，毫秒级
2. **索引先行，不扫全库**：`_索引.md` 把板块→章→节→知识点映射成目标文件名，Agent 先查索引**精确定位**，而不是全文扫描
3. **文件名即地址**：`01-治理.md`、`B-03 属性标准1200-1322.md` 编号即路径，索引命中后直接按名打开
4. **协议约束最小读取**：检索协议规定只读定位到的目标文件——每次讲题实际只读取 1 个文件（几十 KB），全库 5.68 MB 根本不需要加载
5. **按需懒加载**：Agent 只在需要时打开对应笔记，响应速度与知识库总量**无关**，只取决于单文件大小

> 结论：**知识库再大，检索也是毫秒级**；「秒出答案」的瓶颈在 AI 生成讲解（约 2-5 秒），而不是检索。

## 7. 快速开始（10 分钟）

### 第一步：一键下载

```bash
# 方式一：git clone（推荐，后续更新/同步方便）
git clone https://github.com/ZavionWang/exam-knowledge-base.git
cd exam-knowledge-base

# 方式二：下载 ZIP（不想用 git 的话）
# 仓库页面右上角 Code → Download ZIP → 解压即可，效果完全一样
```

### 第二步：把这段提示词粘给你的 AI

打开你的 AI 客户端（Claude Code / dsh / 任何支持读文件的 AI），粘贴下面这段话（把 `<项目路径>` 换成你解压/克隆的实际路径）：

```text
我下载了考试知识库项目（exam-knowledge-base），项目路径：<项目路径>
请先读项目根目录的 START-HERE.md，然后严格按里面的引导协议执行：
1. 问我建档需要的信息（考什么考试、教材格式、教材路径、考纲）
2. 根据我的回答完成建档：建科目目录、复制骨架、生成索引、摄入教材、实例化检索协议
3. 建档完成后告诉我怎么开始刷题
```

AI 会先读 `START-HERE.md`，然后问你四个问题，再一步步完成建档。

### 第三步：回答四个问题

你的 AI 会先问你：

1. **考什么考试？**（考公/考研 · CIA · CPA · CFA · 法考 · 软考…）
2. **教材是什么格式？**（电子版 PDF / 扫描件 / Word）
3. **教材存放在哪？**（文件夹路径）
4. **有官方考纲吗？**（大纲 / 章节列表）

### 第四步：开始刷题

回答后 AI 自动建档：建科目目录 → 复制骨架 → 按考纲生成索引 → 摄入教材 → 实例化检索协议。然后直接发题：

```
用户发题 → 查 _索引 定位（板块→章→节→知识点）
→ 打开对应章节精讲 → 四段式输出：
   考点定位 → 准则/大纲依据 → 思路拆解 → 干扰项解析
→ 错题回写错题库（带知识点 ID）
```
